# Superpowers Drafts

このディレクトリは、設計検討中のspecと実装計画を一時的に保管する作業領域である。

## 扱い

- ここにある文書は正式な仕様ではない。
- 正式な共通設計は`architecture/`、取得仕様は`data-collection/`、schemaとmetricは`data-model/`、運用手順は`operations/`で管理する。
- 正式文書や実装から、このディレクトリの内容へ依存しない。
- 採用した内容は、該当する正式文書へ責務単位で反映する。
- 実装完了後も残す必要がある設計だけを正式文書へ記録する。
- 古くなった計画を現在の仕様として扱わない。

## 下位ディレクトリ

- `specs/`: 設計案
- `plans/`: 実装順序や作業単位の案
